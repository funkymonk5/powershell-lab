# Bulk Microsoft 365 User Creation Script

This PowerShell script automates the creation of Microsoft 365 / Azure AD users using the Microsoft Graph PowerShell SDK.

## Features
- Bulk user creation from CSV  
- Automatic password generation  
- Usage location assignment  
- License assignment  
- Error handling and logging  
- Modern Graph API (recommended by Microsoft)
